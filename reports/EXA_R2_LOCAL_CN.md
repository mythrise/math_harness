# Exa 附件 R2 本机升级验收

日期：2026-09-08。基于 `5e4fe52` 的 0.3.0 仓库升级 Exa 研究层。附件 ZIP SHA256：`43e111f1ed263c12cccfcce837a322557684a7878a8c64800711e4da6ef664b7`；原文件保留在 `docs/exa-r2-handoff/`，其清单逐项匹配。本报告区分本机新结果与附件生产者的离线日志。

## 实施与验证结果

- 严格 sidecar、冻结 UTC/版本/范围、请求编译、Bearer、逐次预算与恢复、缓存与版本快照、逐假设支持/反方查询、定向精读、原文偏移与独立语义审查已接入 Controller。旧 profile 与无 sidecar 路径保留。
- 最终本机基础设施测试 **270 passed**；最终 Docker 全仓 **358 passed，0 failed，0 skipped**。新增 R2 **66 项**。附件参考合同另跑 **31 项**，不混入仓库计数。
- Docker 数值诊断两轮，各 **98 条记录、9 项诊断**；去掉耗时字段后结果与诊断完全一致。未运行外部候选，没有性能晋级结论。
- **LIVE_EXA_HTTP**：4 次真实 HTTP，请求均成功，实际费用字段合计 **$0.025**，未知费用次数 0。支持 6 来源、反方 8 来源、精读 4 URL；正文长度为 4404、24000、11663、24000 字符，两处命中上限明确不能称全篇已读。`auto + outputSchema` 实际返回 output；生成内容没有进入原文证据。相同查询重放 0 次新增 HTTP、快照一致。
- **SYNTHETIC_FIXTURE + 实际执行**：R2 演示使用固定模型/来源响应、注入 Claude 故障，Docker 实际完成 22 个实验作业，XeLaTeX 实际生成论文 PDF 和 support.zip。恢复以“如有新增调用即报错”的模型/HTTP/执行器验证，0 新调用、产物哈希不变。视觉检查正文引文、结果图表与参考文献页，未见溢出或缺字；没有逐页人工审查全部代码附录。
- **NOT_RUN**：真实 Claude/GPT 整题论文联合验收、Dynamic Highlights 实际能力/覆盖比较、deep 实际服务调用、真实 contest 人工授权。动态/deep 默认关闭，其边界与故障路径使用离线夹具验证。没有批准或提交真实比赛论文。

本机标准 Docker 构建在约 27 kB/s 的依赖下载期间取消，保留日志；最终本机镜像复用上一轮已验证依赖层并复制当前源码，逐个核对全部 42 个 Python 文件的 SHA256。GitHub CI 使用仓库原 Dockerfile 完整构建，具体提交与运行结果由仓库记录。此处不把本机增量镜像称为全新依赖安装。
