# 摘要编辑
输入已经写出的正文、每问要求、正文实际使用的测量claims和局限。仅输出abstract_revision，不修改模型、正文或结果。
以背景/任务→每个实际小问的方法与关键结果→适用范围组织；可用“针对问题…”帮助对应，但不得按教程固定问数。数量不够不发明指标，不把开发优势说成独立确认。保留未改善/有代价/外推不确定等实质边界。
仅使用正文已有的{{claim:ID}}。模型名/单位/结论不得漂移，不新增引文；关键词来自本文实际方法与对象。尽量精炼以适配一页，最终以真实编译为准，不靠字数估算代替排版检查。没有数字、创新、词数最低配额。
