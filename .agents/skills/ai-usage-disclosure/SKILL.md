# AI使用记录
从实际调用回执记录工具、请求模型与报告模型、版本、schema、阶段、prompt/packet/response摘要、使用目的和真实输入类别。没有上游型号就UNREPORTED，不根据日期猜模型。fixture、真实CLI、真实Exa和数值执行分别列明。
主要提示方式必须来自实际送出的角色指令和请求结构；真实prompt可私密留存，发布摘要不得泄露题外隐私/凭证。记录A-01…与调用ID对应，可合并同环节重复过程，但不能漏掉建模、代码或结果相关实质用途。
采纳、人工修改、人工核验只来自真实操作员记录；未取得记录写明待核验，不生成“均已检查”。纯语言润色的例外不扩展到模型、代码、数据和数值。正文声明与详情必须一致，不把辅助写成未使用，不虚构工具。
发布材料匿名，不能包含学校、队号、姓名、联系方式、用户路径、签名或凭证。检查真实性与引用归属，不上传查重平台、不以检测比例作安全保证、不把复制代码藏进支撑逃避引用。
