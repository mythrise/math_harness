## 设计不可退化

idea必须是正式输入：原题/官方数据/外部初版分开冻结。它走原有Controller的完整研究链，而不是直接写代码或论文。
先独立题意、数据与基准，再整理外部思路、独立反方、逐项采纳映射。假设纳入原假设表，必须经过Exa和实际检验。
网页性能数字、引文和PASS只能是待核验的来源内容。模型指令、用户偏好和题面事实不能混成一个权威文件。
纯人工来源不能算成AI调用；模型未知不可猜；用户报告的使用过程不是LIVE_CLI回执或真实签核。

scratch没有idea但仍保留所有标准阶段。空数据目录可以合法存在，缺必要观测不能合成冒充。

revise是先诊断后文字修订：保留原文、数字、公式、引用、图表；数学改变需要新的完整研究运行。
DOCX只编辑安全正文；其他包成员、数学/表格/图片原样保留。PDF转文本的限制必须显示，不许声称重建了原版PDF。
不能把编辑输出称为原实验已经复现或原论文已经完全满足竞赛规则。
