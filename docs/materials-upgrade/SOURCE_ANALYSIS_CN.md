## 2. 三类采纳等级

**A：可落实为可执行合同。** 原文条件定位、实际子问覆盖、数据来源及训练内预处理、模型适用性比较、单因素改进、真实计算与误差、原文引用、摘要正文一致性、匿名及AI记录。

**B：可选写作或实验建议。** 摘要分段、三线表、每问流程图、灵敏度/压力测试、不同模型对照、Word与LaTeX跨格式校验。必须按题目和数据选用；图表数量、字段数、字数、配色不自动决定质量。

**C：拒绝或需要外部核验。** 国奖保证、正文≥25页、公式≥30（文内又写≥15）等数量红线；固定异常/缺失处理；以相关系数直接代替可靠性证明；所有模型一律RMSE/MAPE；查重阈值“安全线”；无许可证的代码直接入生产；虚构数据/文献/运行/人工签核。

S11内部还有“只能Graphviz”与“强烈推荐PPT”、摘要700–850字与800–900字符等冲突；本次没有隐式选其中一个作为官方规定。抽取的是可读、可审、可复现的目标，而非这些数量和工具限制。

## 4. 模型资料包使用边界

只解析语法并不等于算法正确、依赖可用或实际可复现。S03包含嵌入讲义、Python2式语法、重复内容、占位路径和未展开RAR。所有原文件都未导入生产worker，未运行原脚本。S07保留工作表和行号供阅读；模型手只能选择已安装method card，参考目录条目不能获得执行许可。本轮没有训练21个外部基础模型，也没有重新优化MOSAIC数值内核。
