# 数学建模算法库全量升级：研究、数学机制与实施边界

**版本：Algorithm Library 0.3.0；调研截至 2026-09-08。**

本轮对 `mythrise/math_harness` 当前 `algorithms.py` 中的十个方法族逐一升级。主分支核对快照为 `69dc9247ff2408e05d23e0bb7be1395f77db9c64`；算法入口原始 Git blob 为 `4b41b864c3d3f76cb6dcdc6fafca3ddf1d428f33`。十个条目不是十个完整独立求解器：旧版部分只是指向 SciPy 的方法卡。因此本轮既包括算法实现，也包括适用域、独立验证、研究候选和升级裁决。

完成的是第一轮全库工程升级与分领域研究设计，不是对所有前沿模型的权重复现，更不是“全面达到 SOTA”的证明。新增 CPU 模块经过实际测试；21个外部候选条目全部标为 `EXTERNAL_NOT_RUN`，不自动下载权重，不以轻量占位器冒充模型。

## 1. 从 MOSAIC 升级路线提取的共同原则

你之前 v9-CGR 到 v14 的关键，不是“到处增加五个专家”，而是：冻结可靠主干，只在可识别的困难场景中增加受控残差；未触发时不扰动主干随机轨迹；额外搜索消耗真实预算；最终裁决来自原问题的评价器；对失败候选回滚，而非修改评价标准。

统一的算法系统分成四层：

```text
可信问题合同 → 结构化适用域筛选 → 冻结主干 / 有条件候选
          → 独立校验 → 原始证据 → 升级门禁 → 有范围的发布
```

其抽象式是：

\[
 x_0=A_0(z),\quad \tilde x=R_\theta(z,x_0),\quad
 x_{out}=\begin{cases}\tilde x & \text{如果验证及接受条件成立}\\x_0&\text{否则。}\end{cases}
\]

这里的 `R` 可以是完整邻域求解，不一定是向量加法。对预测器可以写成 `f0 + αr`；对可行解是邻域搜索；对采样是带密度校正的分布变换；对统计推断是外层校准或风险门禁。不同算法不能共用同一收益定义、同一预算或同一正确性证明。

### 借鉴前沿大模型，但不偷换概念

DeepSeekMoE/V3 的共享专家、细粒度条件计算和路由负载修正，可启发“便宜公共求解器＋少量特定专家”。负载均衡属于调度，不应添加到原数学目标中。[S22]

Engram 将静态知识查找与动态计算分开。可迁移的工程思想是：重复的数学原语、数据规格、已验证程序和失败机制查表复用；难问题才调用模型。这不是在本工程里复现了 Engram 网络，也不能把字典缓存的新名字当成论文创新。[S21]

AlphaEvolve 的有价值部分是“程序候选由外部可执行评价器选择”。本工程沿用已有 autoresearch 迭代，不允许模型自己编写通过分数，不允许改冻结 evaluator。其性能结论仍须由我们的数据、基线与预算重新建立。[S20]

## 2. 十个方法族的升级矩阵

|---|---|---|---|
| LP | HiGHS封装、行缩放、原量纲残差与状态 | 已认证求解器中的参数/预处理策略 | 不取代HiGHS |
| MILP | 整数核验、原问题上下界、可行邻域修复 | LLM-LNS、LLM4Branch、EnCore | 仅局部建议，不伪造全局最优 |
| MOSAIC多目标 | 原v14保持，补独立前沿/目标审计 | SEEMOO、CMOEA-AOP式受控专家 | 新策略不自动激活 |
| 回归/分类 | 训练内组合选模、交叉拟合残差、独立校准 | TabPFN-3、TabICLv2 | 残差默认关闭 |
| 时序 | 滚动原点组合，季节残差、滞后岭回归 | TimesFM3、TiRex2、Toto2、Chronos2 | 保留所有经典基线 |
| TOPSIS/评价 | 固定外部锚点、权重不确定性、AHP一致性 | 稳健偏好学习、排名稳定性研究 | 不替用户捏造偏好 |
| 最短路径 | 零权重、负边、启发式一致性核验 | TSP/VRP另支：DyNACO、EFLOCO | 不用神经模型代替精确最短路 |
| ODE/动力学 | DOP853/Radau、双容差诊断、守恒检查 | Walrus、PDEformer2、PhysicsCorrect | 数值解与方程约束继续权威 |
| Monte Carlo | Scrambled Sobol、独立重复、独立pilot控制变量 | FM-ISQMC与学习型重要性采样 | 不把偏置样本当无偏估计 |
| 统计/聚类 | 独立单位配对区间、Holm/BH/BY、聚类诊断 | SCoRE、模型无关选择风险控制 | 推断不由LLM置信度决定 |

## 3. LP：升级求解可靠性，不与精确算法争夺定义

最小化 `cᵀx`，约束 `l ≤ Ax ≤ u`、`lb ≤ x ≤ ub`。新增 `solve_linear` 把可选行缩放仅用于数值求解，再回到原始 `A,l,u` 校验：

\[
 v=\max\{0,\max_i(l_i-a_i^Tx),\max_i(a_i^Tx-u_i),\max_j(lb_j-x_j),\max_j(x_j-ub_j)\}.
\]

`v` 超容差即拒绝。必须区分求解器报告最优、达到限制、不可行、无界和数值失败。求解器状态与双精度残差是数值证据，不是形式化有理数证明。新增API仍以SciPy/HiGHS为计算内核。[S24]

下一轮研究可考虑自动选择 presolve、缩放和求解模式。但不得让网络删去未经证明冗余的约束、改变目标、修改容差以制造通过。验证集合至少包括病态缩放、不可行、无界、等式、负变量、退化和稀疏大实例。比较需计入全部重启和模型建议开销。

## 4. MILP：学“搜索哪一小块”，而非假装网络能给最优证书

LLM-LNS（ICML2025）把LLM用于邻域策略的程序演化；LLM4Branch将程序发现用于分支策略；EnCore（2026-08-20预印本）学习早期可行解中哪些变量的赋值可能在后期保留。这些方向都适合你的可靠主干＋残差路线。[S07-S09]

本轮实现 `milp_neighborhood`：先验证现有可行解 `x0`；仅允许候选建议自由变量集合 `F`。整数变量中不在 `F` 的坐标固定为 `x0` 的既有赋值，连续变量保留自由。对子问题用HiGHS求解，只有可行且目标不劣才接受。

**重要界限：** 固定变量得到的是原可行域的子集。子问题最优不代表原问题最优，子问题的对偶下界不能作为原问题的全局下界。代码显式返回 `LOCAL_NEIGHBORHOOD_ONLY` 和 `dual_bound=None`。

未来专家建议可按四种失败模式划分：早期找不到可行解、 incumbent长期停滞、可行解很好但证明慢、约束耦合导致局部邻域无效。只在确有相应证据时激活。消融比较同一求解器的随机自由集、经典local branching、学习自由集、去掉一致性和去掉回退；测试MIPLIB及不重合的实例族，统一全流程秒数和线程。不能把这些尚未跑的实验写成EnCore已部署。

## 5. 多目标：冻结 MOSAIC v14，新增分支只能带证据进入

附带的MOSAIC代码和参数文件未改。执行仍使用原始 `mosaic_solve`，并独立检查 `ledger.spent == result.evaluations == budget`。新增 `pareto_audit` 重算每个返回点的目标，检查返回集合内部的非支配性，单独记录验证调用次数。

该审计不证明找到了完整真实Pareto前沿。标量化方向、约束可行性、HV参考点和变量编码仍需问题合同约束，不能靠审计函数补全。

前沿候选有SEEMOO的代理模型调度、CMOEA-AOP的受约束算子组合。[S10-S11] 推荐后续分支：昂贵目标的代理残差、多目标高维参考方向、多模态决策空间覆盖、约束可行性恢复。按问题族选择，不把原双目标ordered-subset快速分支强行用于一般非线性约束或噪声目标。

必须与原incumbent、官方NSGA-II/III、MOEA/D以及对应场景的强算法按同FE预算比较，同时另报训练、推理和总时间。禁用残差时必须保持主干输出及随机流；多种子和留一问题族确认后才允许默认晋级。本轮没有产生新的MOSAIC性能冠军。

## 6. 回归与分类：共享预测主干、残差候选和独立风险层

截至核验日期，最新候选不应仍停留在TabPFNv2：TabPFN-3与TabICLv2均有官方报告/代码。其共同值得借鉴的是利用大量合成任务形成先验，再根据当前小数据上下文预测，而不是“对每个比赛小表格从头训练大Transformer”。[S01-S02]

本轮可运行层使用 `fit_tabular`：回归有OLS、Ridge、Huber、Histogram GBDT，分类有Logistic/Histogram GBDT。预处理放在训练折内部；支持IID、GroupKFold和TimeSeriesSplit。函数只接收训练数据，不接收测试或校准标签。

残差候选为：

\[
 \hat f(x)=f_0(x)+\alpha r_\theta(x),\quad
 e_i=y_i-f_0^{(-fold(i))}(x_i).
\]

`rθ` 拟合交叉拟合残差，`f0` 在训练集重拟合。该候选当前仅允许IID，不能把随机KFold内层用于时序或分组数据。`α=0` 时跳过残差训练，输出与同一个Ridge主干逐字节相同，不消耗额外随机序列。

首版仅按平均验证损失选残差出现退步。第二版增加“相对最好经典候选，在每个验证折都超过预设收益阈值”的门禁；新种子上仍有非线性场景退步，所以 **include_residual默认False**。这一结论是本轮真实负结果，不应因希望升级成功而隐去。

选择模型后，另留校准集建立区间。标准split conformal阈值为：

\[
 k=\lceil(n_{cal}+1)(1-\alpha)\rceil,\quad q=s_{(k)};
 \quad C(x)=[\hat y(x)-q,\hat y(x)+q].
\]

若 `k>ncal`，返回无穷区间而不是误用最大残差。只有校准与测试可交换、校准未用于选模等条件成立时才有边际覆盖保证；不保证条件覆盖，更不保证分布漂移下依然有效。2026年TFM不确定性比较研究也提示，点预测好不等于细分群体的覆盖可靠。[S23]

未来基准使用TabArena/TALENT，比较CatBoost/LightGBM、TabPFN-3、TabICLv2及受控残差，统一外层划分与预算；同时报告RMSE/AUC、proper scoring rule、覆盖、区间宽度、延迟、内存。权重许可单独核验；源码许可与模型权重许可不能混为一谈。

## 7. 时序：按历史证据与预测步长选择专家

本轮替换单一直线外推推荐的，是保留直线、last-value、seasonal-naive、近期趋势＋季节残差、lagged Ridge的滚动原点组合。各验证窗口不重叠，选择完成后才对真正未来输出。当前本地接口是规则采样、单变量，无外生变量；不宣称已解决缺测、非规则采样和多变量。

前沿层纳入TimesFM3.0（2026-08）、TiRex2、Toto2和Chronos2。机制分别涉及原生多变量/协变量、循环状态、不同规模/集成先验、上下文组注意力。[S03-S06] 不同模型的全部API、权重和硬件后端没有在本环境下载复现。

注意两个实际落地限制：TimesFM3.0源码与权重许可不同，官方仓库当前限制3.0权重用于非商业、非生产；TiRex2开源仓库与Pro附加的流式更新、硬件优化等功能有边界。[S03-S04] 部署前必须再确认。

后续研究方向不是“把整个时间序列都交给一个大模型”，而是：按季节强度、结构突变、上下文长度、预测步长、协变量可用性划分困难模式；按历史回测选择便宜统计基线或基础模型。任何所谓未来协变量都必须在预测时真正已知。外层用按时间/领域隔离的任务，报告MASE、WQL/CRPS、成本；不能用IID conformal直接给有依赖时序贴覆盖保证。

## 8. 评价：从漂亮排名改为有偏好来源的稳定决策

旧TOPSIS的向量归一化与理想点随备选方案集合变化，可能导致插入方案后原方案相对排名改变。本轮实现固定外部锚点 `Lj,Uj`，而不是每次从当前样本重新选最大最小值：

\[
 z_{ij}=(x_{ij}-L_j)/(U_j-L_j),\quad v_{ij}=w_jz_{ij},
 \quad C_i={\|v_i\|\over\|v_i\|+\|v_i-w\|}.
\]

成本型列先变为 `1-z`。当外部锚点和权重保持不变，插入新方案不改变原方案分数；超出锚点域时显式拒绝，不悄悄截断。该性质不说明权重或效用模型一定正确。

新增Dirichlet权重抽样得到排名接受度矩阵；完全同分的方案均分占据的名次，避免按行号偏置。AHP给出一致性比例，但一致性不是专家偏好的真实性。LLM只可辅助解释指标与提问，不得自编“客观重要性”。2025年的排名稳定性研究可作为更深层诊断候选，不应盲目发明一套新权重公式。[S12]

消融应固定数据，比较原TOPSIS、固定归一化、固定理想点、二者同时固定；外加权重和量纲扰动、支配单调性、平局与重复方案。这里的改善指标是稳定性与偏好一致，不是任意捏造的预测accuracy。

## 9. 图算法：不能混淆最短路与旅行商

最短路径是一个方法族，TSP/VRP是另一个问题。DyNACO的动态神经引导和EFLOCO的离散flow-matching值得用于组合路线搜索，但其论文性能不能移植成Dijkstra的改进证书。[S13-S14]

本轮 `shortest_path` 支持零代价边、平行边、断连、负边和可达负环。非负边使用Dijkstra；有负边使用Bellman-Ford。启发式可以由模型提出，但只有满足 `h(goal)=0` 且每条边满足 `h(u)≤w(u,v)+h(v)` 才允许A*；否则回退为零启发式的Dijkstra，不删除任何边。

神经TSP/VRP未来分支应把学习输出变成破坏/修复/候选边优先级，而非未经证实的硬剪枝。基线至少包含LKH/HGS/PyVRP等对应任务强实现，报告可行率、gap、总推理/搜索时间。TSP上的模型不能直接宣布适用于时间窗、容量或非欧氏路网。

## 10. 动力学：基础模型负责加速候选，方程与数值诊断负责审查

Walrus和PDEformer2说明PDE基础模型可以跨系统共享先验；PhysicsCorrect研究预测后的方程残差校正。[S15-S17] 这与位姿世界模型中“生成轨迹＋物理约束检查”的思想有相通之处，但需要真实的方程/边界条件，而不能只检查曲线看起来平滑。

本轮可运行层为显式ODE：非刚性默认DOP853、声明刚性则Radau；相同输出网格上运行两个容差，检查差异，并核验用户明确给出的守恒关系和非负性。所有RHS调用包括数值Jacobian中的调用都计入预算。

线性约束投影采用最小二乘修正 `x'=x+A†(b-Ax)`，只保证满足可一致的线性不变量，不能保证动力学正确或非负。双容差差异也是诊断，不是严格误差上界。PDE/神经算子的下一轮需基于真实网格、边界、长程稳定性、inverse-task精度和重复求解摊销成本，不能在一次小题上用训练开销更大的模型宣称省时。

## 11. 蒙特卡洛：采样规律可以学习，概率校正不能省

新增 `integrate_unit` 支持独立MC与scrambled Sobol。每个Sobol重复使用 `2^m` 个点，误差从独立scramble的均值间估计：

\[
 \widehat{SE}=sd(\hat I_1,\ldots,\hat I_R)/\sqrt{R}.
\]

绝不能把一个Sobol点集内部的点当IID算误差条。[S25] 可选控制变量系数由独立pilot估计：`f(x)-βᵀ(h(x)-E[h])`，pilot真实函数评价也计入预算。Student-t区间是近似，零命中稀有事件不能证明风险为零。

FM-ISQMC的研究方向是用flow变换改善采样，再用重要性权重补偿传输误差；其收敛结论依赖正则性和增长条件，不能直接声称任意神经采样都无偏或有近似N^-1误差。[S18] 后续专家分为平滑低有效维度、尖峰/尾部、昂贵积分和已知控制变量，不为每个积分强行训练normalizing flow。

## 12. 统计：大模型不会取消抽样单位、多重检验和因果假设

新增 `paired_summary` 可先按真正独立单位聚合再bootstrap；同一个人/同一个实例的窗口不能当多个独立样本。输出均值增益、近似区间和单侧符号检验；符号检验检验胜率，不与均值检验混为一谈。`adjust_pvalues` 明确区分Holm、BH、BY所需假设。聚类输出轮廓系数和多种子稳定性，但不据此证明真实群体存在。

SCoRE将conformal与e-values结合做选择性风险控制，是未来“何时信任一个预测专家”的研究候选。[S19] 当前没有复现其代码或继承其定理。因果分析未来需单独的识别假设、cross-fitting、正交得分与混杂敏感性；预测好不等于因果模型成立。

## 13. 每一轮晋级的合同

每个升级必须包含：适用域、冻结主干、修改点、真实预算单位、独立评价器摘要、负控制、强基线、单因素消融、开发/确认划分和可拒绝的验收准则。

`promotion_decision` 校验：原始评价JSON与摘要、候选和所有基线/消融的代码摘要、完整实验矩阵、确认阶段、指标、预算、单位、未见过的问题族，再做多重比较修正及收益/退步比例判定。未满足条件返回HOLD；即使满足也只能是 `PROMOTE_WITHIN_SCOPE`，不是全局SOTA。

该函数消费控制器维护的可信记录，不是一个密码学身份系统。拥有文件写权的人能伪造整个记录，因此仍需既有harness的权限、审批、哈希账本和独立审查。模型不能自行填绿色valid表格后调用它完成自证。

本轮对比结果未满足完整外部强基线晋级条件，所以 `global_promotions=0`。所有外部基础模型保留NOT_RUN。实践模式可使用已测试的CPU封装做新题，不改变竞赛模式原有的人类签核。

## 14. 后续实验优先级（不是已完成清单）

第一组优先：真实表格和真实时序，因为原库基线最弱、现成模型可复用。按TabArena/TALENT与GIFT-Eval/fev等任务做有界子集，先取得真实权重/许可/调用成本；与强GBDT及统计模型比较，检验其条件优势而非追一个汇总榜。

第二组：MILP领域内邻域策略和MOSAIC难例残差。前者受益于可靠可行解与精确子问题；后者已有较成熟主干，应把新增复杂度限制在已诊断缺口。

第三组：TSP/VRP神经搜索、PDE基础模型和流采样。它们需要更专门的数据、训练和执行后端；只有重复求解规模足够、质量代价明确，训练摊销才可能有意义。

每组都要保存失败候选，并在新机制冻结后使用新实例或新问题族验证。不能反复查看同一确认集调门槛，再把它叫“独立确认”。
