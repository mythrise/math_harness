# 需要 Codex 实施并运行的验收测试（本交接未执行）

## 配置与请求合同

1. 当前兼容profile合并DEFAULT_CONFIG后通过原有验证；原profile未变。
2. 原工作区不含sidecar时行为/恢复不变；新策略字段未经解析不能悄悄忽略。
3. /search内容仅在contents内；/contents内容在顶层；内部字段不能泄露为API参数。
4. publication能力可用时正确发送；不支持时记录且仅走预定义范围内降级，400/422不循环重试。
5. 三条时间路线正确计算月末/闰年/UTC截止；恢复不改变截止时间；晚于cutoff的新版本不用于as-of结论。
6. 新key/enum/无限数值/无效字符串/布尔冒充整数均按schema拒绝。

## 证据与科研有效性

7. 超过10000字符的关键原文能被精读获得；24000上限命中不能声称读完全篇。
8. fake quote、未知source_id、陈旧snapshot和错引支持关系被发现/阻断。
9. summary/output生成文字不能作为原文证据；模型confidence不自动使条目通过。
10. 每个关键假设具备支持/反方query映射；同一条query可覆盖多个，但不能空泛声称全覆盖。
11. 无反例命中不等于证真；经验假设须有实际test接口，未执行不能通过执行门禁。
12. DOI/arXiv镜像只计一个work；版本和hash冲突不会被URL字典覆盖。
13. 有效FAIL经Claude/GPT故障接管后仍保留；反方上下文无作者PASS先验。

## 网络容错与限额

14. 429+Retry-After、503、超时分别有限重试且预算逐次增加。
15. 401/403停止自动请求并保留认证等待状态，不使用匿名服务。
16. 四URL contents两成功两失败，成功只取一次，后续仅重试失败项。
17. HTTP200空结果记EMPTY并允许另一个查询；不能转换为“文献不存在”。
18. 两并发争抢最后一次预算时总尝试数不超80；熔断single-half-open正确。
19. 相同请求single-flight；未知在途进程不自动重复启动。
20. costDollars缺失为UNKNOWN；探测、重试、精读全部计入预算，不宣称固定花费。

## 缓存与安全

21. 同工作区恢复不触发网络；新工作区过期规则/API资料按策略刷新。
22. 策略/内容/授权范围变化使依赖结果失效；被拒证据仍在审计链。
23. 凭证不进入URL、配置、模型子进程、数值容器、stdout、快照或支撑包。
24. 私有URL、凭证URL、重定向、恶意抓取指令、题面/原数据外发被拒绝。
25. contest未批准query或范围扩大被阻断；没有操作员密钥不能伪造批准。

## R2新增：附件明确的动态摘录与接口细节

29. dynamic=true且含highlights.maxCharacters时，在HTTP前拒绝。
30. 每个动态请求/重试都有准确Exa-Beta；稳定请求不误带；缓存键包含模式和Beta版本。
31. 默认禁用动态，opt-in后仍需能力检查；能力检查计入预算。动态模式与逐来源模式的实际摘录覆盖需比较，不用响应形状证明服务执行机制。
32. 明确预览不支持才允许已授权稳定退化；保持query/domain/time；认证错误、未知400、有效FAIL不能触发。
33. 带元数据但没有highlight的来源仍保留；关键来源需定向精读，不能因共享分配而消失。
34. Bearer认证由原凭证加载器运行时注入，缓存/日志不含Authorization或x-api-key。旧显式认证方式兼容，不按401自动切换。
35. 原始HTTP嵌套键camelCase；仅在SDK路径使用snake_case。两条调用路径不得混用或悄悄忽略嵌套字段。
36. outputSchema超过限制/含citation时拒绝；本方案只允许更严格的平坦结构。output存在时解析与存储，但生成综合不能直接作为原文。
37. additionalQueries每条都检查隐私/授权；放在auto路径拒绝，未知参数拒绝。
38. source.text、highlights、summary、output分离存储；grounding.confidence不自动升级证据状态。
